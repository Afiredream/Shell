## 1. 安装与启动

```sh
cargo build --release          # 编译，产物在 target/release/shell-lite
cargo install --path .         # 可选：装进 ~/.cargo/bin
```

三种启动方式：

| 方式 | 命令 | 说明 |
| --- | --- | --- |
| 交互模式 | `shell-lite` | 显示提示符，逐行输入，`Ctrl-D` 退出 |
| 执行一条命令 | `shell-lite -c "命令"` | 执行完返回命令的退出码，适合写脚本/测试 |
| 查看帮助 | `shell-lite -h` / `--help` | 打印内置命令清单 |

提示符格式是 `用户@主机:目录$`，目录在家下显示为 `~`。**上一条命令失败时末尾变成 `#`**：

```text
user@localhost:~$ false
user@localhost:~# true
user@localhost:~$
```

交互模式需要真实的终端；从管道喂输入时（`echo '命令' | shell-lite`）不会打印提示符和问候语。

## 2. 命令行的基本结构

```text
命令 参数1 参数2 [| 另一条命令...] [> 文件] [< 文件] [2> 文件] [&]
```

- 多个命令用 `;` 或换行分隔，**依次执行**，彼此互不影响；
- 行尾写 `\` 表示下一行接着写（逻辑续行）；
- `#` 在词的开头位置起注释作用，直到行尾。

```text
user@host:~$ echo 一; echo 二
一
二
user@host:~$ echo 多行 \
  续行
多行 续行
user@host:~$ echo 结果 # 这是注释
结果
```

## 3. 管道

`|` 把前一条命令的标准输出接到后一条命令的标准输入；`|&` 表示前一条命令的**标准错误也一起**接过去。

```text
user@host:~$ printf '甲\n乙\n甲\n' | sort | uniq -c
      2 甲
      1 乙
user@host:~$ ls /不存在的路径 |& wc -l
1
```

`命令 2>&1 | 下一步` 与 `命令 |& 下一步` 等价。

## 4. 重定向

| 写法 | 作用 |
| --- | --- |
| `> 文件` | 标准输出写入文件（覆盖） |
| `>> 文件` | 标准输出追加到文件 |
| `2> 文件` / `2>> 文件` | 标准错误写入 / 追加 |
| `< 文件` | 标准输入来自文件 |
| `2>&1` | 标准错误跟随标准输出 |
| `&> 文件` / `&>> 文件` | 标准输出与标准错误一起写入 / 追加 |

```text
user@host:~$ echo 第一版 > 笔记.txt
user@host:~$ echo 补充 >> 笔记.txt
user@host:~$ cat 笔记.txt
第一版
补充
user@host:~$ cat < 笔记.txt
第一版
补充
user@host:~$ ls /不存在的路径 2> 错误.txt; echo 屏幕上不出现错误
屏幕上不出现错误
```

要点：

- 目标文件**打不开就直接报错**，命令不会被执行（例如目录不存在、没有权限）；
- 重定向写在命令的任意位置都行，`> 文件 echo 内容` 也能用；
- 内置命令（`echo`、`pwd`、`help` 等）同样支持全部重定向，效果与外部命令一致；
- `2>&1` 之后又写 `2> 别的文件` 时，以最后写的为准。

## 5. 后台执行

命令末尾加 `&`，shell 立刻返回，不等待它结束：

```text
user@host:~$ sleep 3 &
[4242] 已放入后台
user@host:~$ echo 马上就能继续输入
马上就能继续输入
```

- 方括号里是子进程号；
- 后台命令在**自己的进程组**里运行，即使接着退出 shell，它们也不会因为读终端而被挂起；
- 本 shell 没有 `jobs` / `fg` / `bg`，后台任务结束也不会打印完成通知；需要时用系统工具 `ps` 查看。

## 6. 引号与转义

| 写法 | 变量 `$名称` | 空白切分 | 通配 `*` | `~` |
| --- | --- | --- | --- | --- |
| 裸词 `abc` | 展开 | 切分 | 展开 | 词首展开 |
| 单引号 `'...'` | **不展开** | 不切分 | 不展开 | 不展开 |
| 多个单引号连写 `'a''b'` | 不展开 | 不切分 | 不展开 | 不展开 |
| 双引号 `"..."` | 展开 | 不切分 | **不展开** | 不展开 |
| 反斜杠 `\x` | `\` 后的字符原样（`\$` 得到 `$`） | 不切分 | 不展开 | — |

```text
user@host:~$ echo 你好  "世界 你好"   '世界 你好'
你好 世界 你好 世界 你好
user@host:~$ echo '$HOME'
$HOME
user@host:~$ echo "$HOME"
/home/user
user@host:~$ echo 带空格\ 的\ 参数
带空格 的 参数
```

引号保护**按字符生效**：`'A'"$HOME"` 里只有 `A` 那段是字面量，`$HOME` 照常展开（得 `A/home`）。单引号里可以写 `\'` 来表示单引号本身。

双引号内只有 `$`、`` ` ``、`"`、`\` 四个字符可以被反斜杠转义；`\n`、`\t` 这类在双引号里**保持字面**（真正的换行/制表符请用 `echo -e`）。

## 7. 变量

```text
user@host:~$ 名字=壳语言            # 赋值，作用于当前 shell
user@host:~$ echo 你好${名字}人
你好壳语言人
user@host:~$ echo $名字
壳语言
```

**给子进程用**时注意两件事：先 `export`，再把 `$名字` 放进**双引号**，让本 shell 先展开：

```text
user@host:~$ 名字=壳语言; export 名字; sh -c "echo $名字"
壳语言
user@host:~$ sh -c 'echo $名字'      # 单引号：$ 原样传给 sh，而 sh 里没有这个变量
$名字
```

- **变量名可以用中文**：首字符是字母或 `_`，其后可以是字母、数字、`_`；
- 名称后面紧跟其它字符时用 `${名称}` 包起来，避免吃掉后面的字；
- `$?` 是上一条命令的退出状态；
- 只写 `名称=值` 的赋值**同时**写进进程环境，所以 `A=1 env | grep ^A=` 能看到；
- `名称=值 命令`（前置赋值）只对这条命令生效，不改 shell 自己的变量：

```text
user@host:~$ X=外层; X=内层 env | grep ^X=
X=内层
user@host:~$ echo $X
外层
```

- 未定义的变量展开为空串。

## 8. 通配符与波浪号

| 模式 | 匹配 |
| --- | --- |
| `*` | 任意多个字符（不含 `/`） |
| `?` | 任意一个字符 |
| `[abc]` | 集合中的一个字符 |
| `[a-z]` | 范围 |
| `[!abc]` / `[^abc]` | 取反 |

- 以 `.` 开头的隐藏文件，只有模式本身以 `.` 开头才会被匹配到；
- 通配只作用于**最后一个路径段之前**的文件名：`日志/*.txt`、`/var/log/*.log` 都可用；
- **没有匹配项时保留原样**（与 bash 一致），例如 `echo *.none` 输出 `*.none`；
- 结果按字符序排序。

```text
user@host:~$ touch 甲.rs 乙.rs 丙.py .隐藏.rs
user@host:~$ echo *.rs
乙.rs 甲.rs
user@host:~$ echo [甲乙].rs
乙.rs 甲.rs
user@host:~$ echo .*
.隐藏.rs
user@host:~$ echo "*.rs"
*.rs
```

`~` 只在词首、且不带引号时展开成家目录：`~`、`~/文档`。`~用户` 这种写法不支持。

## 9. 内置命令

| 命令 | 说明 |
| --- | --- |
| `cd [目录]` | 切换目录；不带参数回家；`cd -` 回上一次的目录并打印 |
| `pwd` | 打印当前目录 |
| `export [名=值...]` | 设置并导出变量；不带参数时列出全部 `export 名=值` |
| `unset 名...` | 删除变量（进程环境里也删除） |
| `env` | 列出全部环境变量 |
| `echo [-n] [-e] 文本` | `-n` 结尾不换行；`-e` 解释 `\n` `\t` `\r` `\\` `\e` |
| `help` | 打印帮助 |
| `true` / `false` | 退出码 0 / 1 |
| `exit [码]` | 退出 shell，不带参数时用上一条命令的状态码 |

```text
user@host:~$ echo -n 不换行; echo 紧接着
不换行紧接着
user@host:~$ echo -e "列 1\t列 2"
列 1	列 2
user@host:~$ cd /; pwd; cd -; pwd
/
/home/user
/home/user
```

内置命令与外部命令的区别只在**在哪里执行**：单独出现时在 shell 进程里执行（所以 `cd`、`export` 能改变 shell）；出现在管道或后台里时，由子进程执行——这时 `cd` 只影响那个子进程，不会改变 shell 的当前目录。

```text
user@host:~$ cd / | cat; pwd
/home/user
```

内置命令如果和服务器的同名程序重名，内置优先（例如 `echo`）。

## 10. 启动文件

shell 启动时（交互模式和 `-c` 模式都会）逐行执行 `~/.壳语言rc`，可以放变量、`export`、`cd`：

```sh
# ~/.壳语言rc
export 编辑器=vim
项目=~/Projects
cd $项目
```

文件不存在则跳过；其中某行出错不会让 shell 起不来，执行完启动文件后提示符里的状态码归零。

## 11. 退出状态

- 外部命令：程序的退出码；被信号杀死时为 `128 + 信号号`；
- 命令不存在：127；存在但没有执行权限：126；
- 内置命令本身失败（例如参数不对、目录不存在）：1；
- 语法错误、重定向目标打不开：2 / 1；
- 一条管道取**最后一段**的状态码；
- `shell-lite -c "..."` 的进程退出码就是最后一条命令的状态码；`exit N` 则返回 N。

```sh
shell-lite -c 'exit 7'; echo $?                # 7
shell-lite -c '不存在的命令'; echo $?            # 127
shell-lite -c 'cat /不存在的文件'; echo $?       # cat 自己返回的 1
```

## 12. 报错信息对照

| 信息 | 原因 | 怎么改 |
| --- | --- | --- |
| `语法错误：引号 ' 未闭合` | 单/双引号没有成对 | 补上引号 |
| `语法错误：缺少命令` | `|`、`&`、`;` 后面没有命令，或者 `&&`、`||` 这类不支持的语法 | 补齐命令 |
| `语法错误：重定向缺少目标文件` | `>`、`2>`、`<` 后面没写文件名 | 补上文件名 |
| `语法错误：意外的符号 \`(\`` | 不支持子 shell `( )` | 换成 `sh -c '...'` |
| `shell-lite: 某程序: 未找到命令` | `PATH` 里没有这个程序 | 检查拼写或 `PATH` |
| `shell-lite: 某文件: No such file or directory` | 重定向目标打不开 | 检查目录是否存在 |
| `cd: 目录: No such file or directory` | 目标目录不存在 | — |

## 13. 和 bash 的差异速查

| 功能 | 本 shell | bash |
| --- | --- | --- |
| `&&` `||` | 不支持 | 支持 |
| `if` / `for` / `while` / 函数 | 不支持 | 支持 |
| 命令替换 `$(...)` / 反引号 | 不支持 | 支持 |
| 子 shell `( ... )` | 不支持 | 支持 |
| `jobs` / `fg` / `bg` | 不支持 | 支持 |
| 行编辑、历史（方向键） | 不支持 | 支持（readline） |
| `$变量` 展开结果被再次通配 | 不会（只对原样写出的词通配） | 会 |
| 含引号的整词里 `$` | 单引号内不展开；双引号内展开 | 同 |
| `~用户` | 不支持 | 支持 |
| 重定向目标打不开 | 整条命令不执行 | 整条命令不执行 |
| 管道各段并行执行 | 支持 | 支持 |

也就是说：通配只对**命令里原样写出的** `*`、`?`、`[...]` 生效；从变量里展开出来的 `*` 会原样交给程序。
