## 1. 安装与启动

```sh
cargo build --release          # 编译，产物在 构建/release/壳
cargo install --path .         # 可选：装进 ~/.cargo/bin（安装后命令名同样是「壳」）
```

只有两个位置参数入口，第一项**自动判断**是脚本路径还是命令文本：

| 第一项 | 行为 | `$0` |
| --- | --- | --- |
| 已存在的文件 | 运行脚本文件，其余参数依次是 `$1`、`$2`…… | 脚本路径 |
| 其它（文本） | 当作一段命令执行（可含换行），其余参数同上 | `壳` |

```sh
壳 脚本.壳 参数1 参数2      # 运行脚本
壳 '回显 你好' 参数1        # 运行一段命令文本
```

没有交互模式，也没有帮助命令：不会出现提示符，也不会读取标准输入当命令；不带参数运行 `壳` 时不输出内容，退出码为 2。


```text
$ cat 问候.壳
回显 你好，$1
$ 壳 问候.壳 世界
你好，世界
```

`$0` 是脚本路径本身。位置参数只在脚本执行期间于 shell 内部可见，不会导出给外部命令；
脚本里的 `退出 码` 决定整个进程的退出码。

## 2. 命令行的基本结构

本章起示例把**命令行和它的输出相邻展示**；把命令行按原样写进脚本文件即可复现（块体保留缩进）。

```text
异步运行 命令 参数1 参数2 [| 另一条命令...] [> 文件] [< 文件] [2> 文件]
命令 参数1 参数2 [| 另一条命令...] [> 文件] [< 文件] [2> 文件] [&]   # 旧写法
```

- 多个命令用 `;` 或换行分隔，**依次执行**，彼此互不影响；
- 行尾写 `\` 表示下一行接着写（逻辑续行）；
- `#` 在词的开头位置起注释作用，直到行尾。

```text
回显 一; 回显 二
一
二
回显 多行 \
  续行
多行 续行
回显 结果 # 这是注释
结果
```

## 3. 管道

`|` 把前一条命令的标准输出接到后一条命令的标准输入；`|&` 表示前一条命令的**标准错误也一起**接过去。

```text
printf '甲\n乙\n甲\n' | sort | uniq -c
      2 甲
      1 乙
ls /不存在的路径 |& wc -l
1
```

`命令 2>&1 | 下一步` 与 `命令 |& 下一步` 等价。

## 4. 重定向

| 写法 | 作用 |
| --- | --- |
| `> 文件` | 标准输出写入文件（覆盖） |
| `>> 文件` | 标准输出追加到文件 |
| `2> 文件` / `2>> 文件` | 标准错误写入 / 追加 |
| `< 文件` | 标准输入来自文件 |
| `2>&1` | 标准错误跟随标准输出 |
| `&> 文件` / `&>> 文件` | 标准输出与标准错误一起写入 / 追加 |

```text
回显 第一版 > 笔记.txt
回显 补充 >> 笔记.txt
cat 笔记.txt
第一版
补充
cat < 笔记.txt
第一版
补充
ls /不存在的路径 2> 错误.txt; 回显 屏幕上不出现错误
屏幕上不出现错误
```

要点：

- 目标文件**打不开就直接报错**，命令不会被执行（例如目录不存在、没有权限）；
- 重定向写在命令的任意位置都行，`> 文件 回显 内容` 也能用；
- 内置命令（`回显`、`输出` 等）同样支持全部重定向，效果与外部命令一致；
- `2>&1` 之后又写 `2> 别的文件` 时，以最后写的为准。

## 5. 后台执行

在命令前加 `异步运行`，shell 立刻返回，不等待它结束：

```text
异步运行 sleep 3
[4242] 已放入后台
回显 马上就能继续输入
马上就能继续输入
```

`异步运行` 作用于**整条命令**（含管道与重定向），写法是 `异步运行 命令 参数...`：

```text
异步运行 回显 你好 | tr a-z A-Z > 输出.txt
[4243] 已放入后台
```

旧写法 `命令 &`（把 `&` 放在命令末尾）仍然可用，但推荐用 `异步运行`——它是命令的一部分，
位置固定、不会被误当成 `&>` 重定向或 `|&` 管道。

- 方括号里是子进程号；
- 后台命令在**自己的进程组**里运行，即使接着退出 shell，它们也不会因为读终端而被挂起；
- 本 shell 没有 `jobs` / `fg` / `bg`，后台任务结束也不会打印完成通知；需要时用系统工具 `ps` 查看。

## 6. 控制流

用 `如果` / `或者` / `否则` 做分支，用 `对于` / `每当` 做循环。块体由**缩进**表示：
块头下缩进，回退即结束，不再写 `结束`。

```text
如果 test -f 笔记.txt
    回显 文件在
否则
    回显 文件不在

文件在
```

条件是一条命令或管道，**退出码 0 为真**。可以用 `正常`、`错误`，或外部 `test`：

```text
对于 项 苹果 香蕉
    回显 水果=$项

水果=苹果
水果=香蕉
```

```text
数字=
每当 test "$数字" != "aa"
    数字=a$数字

回显 数字=$数字
数字=aa
```

`或者` 可以有多个（对应 else-if），`否则` 可省略；它们要与 `如果` 同缩进。块可以嵌套：

```text
对于 外 甲 乙
    如果 test "$外" = "甲"
        对于 内 一 二
            回显 ${外}${内}
    否则
        回显 ${外}无
```

循环体内还能用 `跳出`（退出最近的循环）和 `继续`（进入下一轮），缩进到循环体里。

要点：

- 块体在**当前 shell** 执行，所以 `进入目录`、赋值、目录栈的改动都会保留并影响块外；
- 用缩进表示层级：块头下的行缩进（空格或制表符），缩进退回即块结束；`或者`/`否则` 与 `如果` 对齐；
- `如果`、`对于` 等是保留词，加引号可当普通命令名（如 `"如果" arg`）；
- 条件不能用后台（`异步运行` / `&`），否则取不到退出码；
- 块在脚本里可任意嵌套；文件结束（或 `退出进程`）时所有块结束。

### 函数

用 `函数` 定义（块体同样用缩进）。定义时不执行，调用时才执行函数体：

```text
函数 问候 名字
    回显 你好，$名字

问候 世界
你好，世界
```

参数可用定义时写的名字（`$名字`）取到，也可用 `$1`、`$2`……；`$0` 是函数名。
`返回 [表达式]` 从函数返回，省略时取上一条命令的状态：

```text
函数 判断 数
    如果 test "$数" = "0"
        返回 0
    否则
        返回 1

判断 0; 回显 状态=${?}
状态=0
```

函数体在**当前 shell** 执行：赋值、`进入目录`、目录栈的改动都会影响函数外；
调用结束后命名参数与位置参数恢复为调用前的值。函数优先于同名的内置命令与外部命令。

## 7. 引号与转义

| 写法 | 变量 `$名称` | 空白切分 | 通配 `*` | `~` |
| --- | --- | --- | --- | --- |
| 裸词 `abc` | 展开 | 切分 | 展开 | 词首展开 |
| 单引号 `'...'` | **不展开** | 不切分 | 不展开 | 不展开 |
| 多个单引号连写 `'a''b'` | 不展开 | 不切分 | 不展开 | 不展开 |
| 双引号 `"..."` | 展开 | 不切分 | **不展开** | 不展开 |
| 反斜杠 `\x` | `\` 后的字符原样（`\$` 得到 `$`） | 不切分 | 不展开 | — |

```text
回显 你好  "世界 你好"   '世界 你好'
你好 世界 你好 世界 你好
回显 '$HOME'
$HOME
回显 "$HOME"
/home/user
回显 带空格\ 的\ 参数
带空格 的 参数
```

引号保护**按字符生效**：`'A'"$HOME"` 里只有 `A` 那段是字面量，`$HOME` 照常展开（得 `A/home`）。单引号里可以写 `\'` 来表示单引号本身。

双引号内只有 `$`、`` ` ``、`"`、`\` 四个字符可以被反斜杠转义；`\n`、`\t` 这类在双引号里**保持字面**（真正的换行/制表符请用 `回显 -e`）。

## 8. 变量

```text
名字=壳语言            # 赋值，作用于当前 shell
回显 你好${名字}人
你好壳语言人
回显 $名字
壳语言
```

**给子进程用**时注意两件事：先用 `环境变量` 导出，再把 `$名字` 放进**双引号**，让本 shell 先展开：

```text
名字=壳语言; 环境变量 名字=$名字; sh -c "echo $名字"
壳语言
sh -c 'echo $名字'      # 单引号：$ 原样传给 sh，而 sh 里没有这个变量
$名字
```

- **变量名可以用中文**：首字符是字母或 `_`，其后可以是字母、数字、`_`；名字里的中文标点（`。`、`，` 等）视为名字结束，`你好$名字。今天` 会把 `。今天` 留在正文里；
- 名称后面紧跟其它字符时用 `${名称}` 包起来，避免吃掉后面的字；
- `$?` 上一条命令的状态，`$$` 当前进程号，`$!` 最近后台作业的进程号，`$#` 参数个数，`$0` 脚本名，`$1`、`$2`…… 位置参数，`$参数` 第一个参数，`$参数列表` 全部参数（空格连接）；
- 另有三个默认变量（中文名，脚本参数场景）：

  | 变量 | 内容 |
  | --- | --- |
  | `$参数` | 第一个位置参数 |
  | `$参数列表` | 全部位置参数，空格连接 |
  | `$参数个数` | 位置参数个数 |
  | `$参数对象` | 解析过的参数，JSON 文本：`{"命令行":[...],"选项":{...},"分隔符":"--","剩余":[...]}` |
  | `$当前目录` | 进程当前目录，随时取值都是最新（`进入目录` 之后立即变） |
  | `$脚本路径` | 正在执行的脚本，命令行里的原样写法；不在脚本里或顶层脚本执行完为空串 |
  | `$脚本目录` | 正在执行的脚本所在的绝对目录；`加载脚本` 嵌套时切换为该文件的目录，返回后恢复 |
  | `$返回值对象` / `$返回值JSON` | 最近一次 `读取文本` 的结果（见下方「读取文本与覆写文件」） |
| `${变量.键.子键}` | 把变量的值文本当对象/数组逐层取值；数组用数字下标；键不存在为空串，当前对象只有一个键（INI 的段）时自动进入 |
| `` `${对象.Desktop Entry.Exec}` `` | 键里有空格也没问题，但 `${...}` 所在的词要加引号 |

```text
$ 壳 构建.壳 --parse 甲 --release --输出 json -- 乙
构建.壳 里：
  $参数列表 → --parse 甲 --release --输出 json -- 乙
  $参数个数 → 6
  $参数对象 → {"命令行":["甲","json"],"选项":{"parse":"true","release":"true","输出":"true"},"分隔符":"--","剩余":["乙"]}
```
- 只写 `名称=值` 的赋值**同时**写进进程环境，所以 `A=1 env | grep ^A=` 能看到；
- **启动子进程前会清理不合法的变量名**：systemd 只接受「字母或 `_` 开头、其余为字母数字或 `_`」的变量名，
  所以 `BASH_FUNC_xxx%%`（bash 导出的函数）、以数字开头或含特殊字符的变量**不会传给孩子进程**；
  壳里的变量表不受影响，只是 `env` 里看不到它们；
- `名称=值 命令`（前置赋值）只对这条命令生效，不改 shell 自己的变量：

```text
X=外层; X=内层 env | grep ^X=
X=内层
回显 $X
外层
```

- 未定义的变量展开为空串。

## 9. 通配符与波浪号

| 模式 | 匹配 |
| --- | --- |
| `*` | 任意多个字符（不含 `/`） |
| `?` | 任意一个字符 |
| `[abc]` | 集合中的一个字符 |
| `[a-z]` | 范围 |
| `[!abc]` / `[^abc]` | 取反 |

- 以 `.` 开头的隐藏文件，只有模式本身以 `.` 开头才会被匹配到；
- 通配只作用于**最后一个路径段之前**的文件名：`日志/*.txt`、`/var/log/*.log` 都可用；
- **没有匹配项时保留原样**（与 bash 一致），例如 `回显 *.none` 输出 `*.none`；
- 结果按字符序排序。

```text
touch 甲.rs 乙.rs 丙.py .隐藏.rs
回显 *.rs
乙.rs 甲.rs
回显 [甲乙].rs
乙.rs 甲.rs
回显 .*
.隐藏.rs
回显 "*.rs"
*.rs
```

`~` 只在词首、且不带引号时展开成家目录：`~`、`~/文档`。`~用户` 这种写法不支持。

## 10. 内置命令

| 命令 | 说明 |
| --- | --- |
| `进入目录 [目录]` | 切换目录；不带参数回家；`进入目录 -` 回上一次的目录并打印 |
| `压栈目录 [目录]` | 把目录压入目录栈并进入；不带参数时在当前目录与栈顶之间来回切换，并打印栈 |
| `弹栈目录` | 回到目录栈顶的目录并弹出，打印剩下的栈 |
| `环境变量` | 列出当前 shell 的全部环境变量（每行 `名=数据`，按名排序） |
| `环境变量 名=数据 ...` | 设置并导出（可一次写多个）；数据可带引号也可不带，带引号用于含空格，单引号内是纯文本；`名=` 留空则删除该变量 |
| `删除 名...` | 删除变量（进程环境里也删除） |
| `加载脚本 文件...` | 在当前 shell 里逐行执行脚本：变量、工作目录、目录栈都保留 |
| `读取文本 [文件] [--类型 类型]`（`读取文件` 同义） | 不给类型：原样打印全文（文件或管道输入）；给 `JSON`/`INI`/`文本`：解析并打印 JSON，结果进 `$返回值对象` |
| `覆写文件 文件 内容... [--类型 类型]` | 整份覆写；不给类型按扩展名（`.json`→JSON、`.ini`/`.conf`→INI，其余原样） |
| `输出 文本...` | 直接输出，不追加回车 |
| `回显 文本...` | 输出并追加回车；`-n` 不回车，`-e` 解释 `\n` `\t` `\r` `\\` `\e` |
| `运行 程序 [参数]` | 运行程序并等它结束，与直接敲命令完全一致（可接管道/重定向，失败码照常返回）；`同步运行` 是别名 |
| `正常` / `错误` | 退出码 0 / 1 |
| `退出进程 [码]` | 退出 shell，不带参数时用上一条命令的状态码 |

```text
输出 不换行; 输出 也不回车; 回显 结束
不换行也不回车结束
回显 -n 不换行; 回显 紧接着
不换行紧接着
回显 -e "列 1\t列 2"
列 1	列 2
进入目录 /; 进入目录 -
/
/home/user
```

**`环境变量` 关键字**的三种用法：

```text
环境变量                     # 列出全部环境变量
HOME=/home/user
PATH=/usr/local/bin:/usr/bin
...
环境变量 名字=壳语言          # 不带引号：数据到下一个空白为止
环境变量 问候="你好 世界"      # 带引号：数据里有空格
环境变量 备注='原样 $名字 *'   # 单引号：纯文本，$ 和 * 都不展开
回显 $名字 "$问候" "$备注"
壳语言 你好 世界 原样 $名字 *
环境变量 甲=1 乙=2            # 一次设置多个
```

**中文名称能跨进程传递**：环境变量在系统层面只是一个「名字=数据」的字符串表，名字是中文与否没有区别，
导出的变量会原样传给子进程；子程序的**代码**里能不能直接写 `$中文名`，取决于那个程序的语法（`bash`、`sh` 只认 ASCII 名字），
但它可以通过 `env` / `getenv` / Python 的 `os.environ["名字"]` 等方式读到：

```text
环境变量 名字=壳语言
sh -c 'env | grep ^名字='          # 子进程里确实有这个变量
名字=壳语言
python3 -c 'import os; print(os.environ["名字"])'
壳语言
sh -c 'echo $名字'                  # sh 的变量名只认 ASCII，所以读不到
sh -c "echo $名字"                  # 由本 shell 先展开，再交给 sh：可以
壳语言
```

**数组、对象怎么在命令之间传**：管道和 `$(…)` 只能传字节，所以约定了一种可逆的「值文本」——
数组 `(1 2 三)`、对象 `{键=值 列表=(1 2)}`。

```text
对象=$(读取文本 配置.json --类型 JSON)      # 输出是值文本，$(…) 按对象处理
回显 $对象                                  # {名称=壳 列表=(1 2)}
覆写文件 备份.json $对象                     # 再解析回对象，写成 JSON
列表=$(回显 "(1 2 3)")                      # 输出是值文本，$(…) 按数组处理
```

`(…)`、`{…}` 里带空格时要**加引号**，否则 `(` 会被当成子 shell 语法报错。

内置命令与外部命令的区别只在**在哪里执行**：单独出现时在 shell 进程里执行（所以 `进入目录`、`环境变量` 能改变 shell）；出现在管道或后台里时，由子进程执行——这时 `进入目录` 只影响那个子进程，不会改变 shell 的当前目录。

```text
进入目录 / | cat; pwd
/home/user
```

**目录栈**（`压栈目录` / `弹栈目录`）与 bash 的 `pushd` / `popd` 一致，每次操作后打印栈（当前目录在前，栈顶在后）：

```text
进入目录 /tmp
压栈目录 /usr
 /usr /tmp ~
压栈
 /tmp /usr ~                 # 不带参数：与栈顶互换
弹栈
 /usr ~                      # 回到栈顶并弹出
弹栈
弹栈: 目录栈是空的      # 空栈时报错，状态码 1
```

**加载脚本**：在当前 shell 里逐行执行文件，脚本里设置的变量、切换的目录都会保留下来（与 `sh 脚本` 不同，后者在子进程里执行）：

```text
cat 初始化.壳
环境变量 编辑器=vim
进入 ~/项目
加载脚本 初始化.壳
回显 $编辑器
vim
```

内置命令如果和服务器的同名程序重名，内置优先（例如 `回显`）。

## 11. 启动文件

shell 启动时（脚本模式和文本模式都会）逐行执行 `~/.壳语言rc`，可以放变量、`环境变量`、`进入目录`：

```sh
# ~/.壳语言rc
环境变量 编辑器=vim
项目=~/Projects
进入目录 $项目
```

文件不存在则跳过；其中某行出错不会让 shell 起不来，执行完启动文件后状态码归零。

## 12. 退出状态

- 外部命令：程序的退出码；被信号杀死时为 `128 + 信号号`；
- 命令不存在：127；存在但没有执行权限：126；
- 内置命令本身失败（例如参数不对、目录不存在）：1；
- 语法错误、重定向目标打不开：2 / 1；
- 一条管道取**最后一段**的状态码；
- `壳 "..."`（文本模式）的进程退出码就是最后一条命令的状态码；`退出进程 N` 则返回 N。

```sh
壳 '退出进程 7'; 回显 $?            # 7
壳 '不存在的命令'; 回显 $?            # 127
壳 'cat /不存在的文件'; 回显 $?       # cat 自己返回的 1
```

## 13. 报错对照

| 信息 | 原因 | 怎么改 |
| --- | --- | --- |
| `语法错误：引号 ' 未闭合` | 单/双引号没有成对 | 补上引号 |
| `语法错误：缺少命令` | `|`、`&`、`;` 后面没有命令，或者 `&&`、`||` 这类不支持的语法 | 补齐命令 |
| `语法错误：重定向缺少目标文件` | `>`、`2>`、`<` 后面没写文件名 | 补上文件名 |
| `语法错误：意外的符号 \`(\`` | 不支持子 shell `( )` | 换成 `sh -c '...'` |
| `壳: 某程序: 未找到命令` | `PATH` 里没有这个程序 | 检查拼写或 `PATH` |
| `壳: 某文件: No such file or directory` | 重定向目标打不开 | 检查目录是否存在 |
| `进入: 目录: No such file or directory` | 目标目录不存在 | — |

## 14. 和 bash 的差异速查

| 功能 | 本 shell | bash |
| --- | --- | --- |
| `&&` `||` | 不支持 | 支持 |
| `if` / `for` / `while` | 用 `如果` / `对于` / `每当`（块用缩进）支持 | 支持 |
| 函数定义 | 用 `函数 名称 参数...`（块用缩进）支持 | 支持 |
| 命令替换 `$(...)` | 支持（在隔离的副本里**用本 shell 执行**，中文内置命令也能用） | 支持 |
| 反引号 `` `...` `` | 不支持 | 支持 |
| 子 shell `( ... )` | 不支持 | 支持 |
| `jobs` / `fg` / `bg` | 不支持 | 支持 |
| 行编辑、历史（方向键） | 不支持（没有交互模式） | 支持（readline） |
| `$变量` 展开结果被再次通配 | 不会（只对原样写出的词通配） | 会 |
| 含引号的整词里 `$` | 单引号内不展开；双引号内展开 | 同 |
| `~用户` | 不支持 | 支持 |
| 重定向目标打不开 | 整条命令不执行 | 整条命令不执行 |
| 管道各段并行执行 | 支持 | 支持 |

也就是说：通配只对**命令里原样写出的** `*`、`?`、`[...]` 生效；从变量里展开出来的 `*` 会原样交给程序。
