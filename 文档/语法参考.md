# 壳语言 语法参考

> 本文是**形式化的语法**：词法、文法、展开规则、退出状态。
> 只想知道怎么写命令请看 [使用手册](使用手册.md)；想改解析器请看 [实现说明](实现说明.md)。

## 0. 记号

| 记号 | 含义 |
| --- | --- |
| `甲 乙` | 甲后面跟乙（顺序连接） |
| `甲*` | 甲出现零次或多次（后缀 `*`，与正则无关） |
| `甲?` | 甲出现零次或一次 |
| `[甲]` | 甲可省略 |
| `"..."` | 源文本里的字面字符 |
| `甲 \| 乙` | 二选一 |

本 shell 支持多行控制流块，也支持在一行内写管道、重定向等。块体用**缩进**表示：
块头下缩进、回退即结束，不再使用「结束」。块可嵌套，块体在**当前 shell** 执行
（变量、`进入`、目录栈的改动会保留）：

```text
如果 <条件命令>           // 退出码 0 为真
    <语句...>
或者 <条件命令>           // 可多次，可省略；与「如果」同缩进
    <语句...>
否则                      // 可省略；与「如果」同缩进
    <语句...>

对于 <变量> <词1> <词2> ...
    <语句...>

每当 <条件命令>
    <语句...>

跳出 / 继续               // 退出循环 / 进入下一轮

函数 <名称> <参数名...>    // 定义时不执行，调用时才执行函数体
    <语句...>

返回 [表达式]             // 从函数返回；省略时取上一条命令的状态
```

交互模式下，输入块后按**空行**结束并执行。

`返回` 后面可以是任意**值表达式**：

| 写法 | 值 |
| --- | --- |
| `42` | 整数 |
| `文本` / `"文本"` / `'文本'` | 文本 |
| `$变量` / `${变量}` | 变量的值（文本） |
| `(1 2 三)` | 数组，元素可再嵌套 |
| `{甲=1 乙=(2 3)}` | 对象，有序键值对；**只是数据，没有方法、类或继承** |

返回值存在 `$返回值`（文本形式，数组如 `(1 2 三)`、对象如 `{甲=1}`）。
退出码规则：整数取自身，数字文本按数字取，其余为 0；省略表达式时取上一条命令的状态。

条件是一条命令/管道，可用 `正常`/`错误` 或外部 `test`。
块头必须独占一行，条件不能使用后台（`异步` / `&`），否则取不到退出码。

## 1. 一行输入的文法

```text
行        := 空白* [作业项 ( 分隔符 作业项 )* ] 注释? 空白*
分隔符    := ";" | "&" | "\n"                     // 旧写法 `&` 同时把前一项放进后台
作业项    := ["异步"] 管道 重定向*              // 「异步」把整条作业放进后台
管道      := 简单命令 ( 管道符 简单命令 )*
管道符    := "|" | "|&"
简单命令  := 赋值* ( 词+ 重定向* )?                  // 只有赋值时是「纯赋值命令」
赋值      := 名称 "=" 值词
名称      := (字母 | "_") (字母 | 数字 | "_")*
```

补充规则：

- 重定向可以写在管道任意段的前后，但**归属整条作业**：
  - `>` / `>>`：整条作业（即最后一段）的标准输出，`echo b | cat > 文件` 与 `echo b > 文件 | cat` 都把 `b` 写进文件；
  - `<`：整条作业（即第一段）的标准输入，**并且优先于管道**。`echo b | cat < 有内容.txt` 输出文件里的内容、`b` 被丢弃；
  - `2>` / `2>&1`：作用于按顺序等待时第一个还没结束的段——对单段命令就是它自己；
- `;` 与换行等价；连续写 `;;` 不会报错（空语句被忽略）；
- `异步` 是后台关键字，写在作业开头：`异步 echo a` 把**整条作业**放进后台；
  它只在命令名位置、未被引号包住时生效，单独写（后面没有命令）报「缺少命令」；
- 旧写法 `&` 是分隔符 + 后台标记：`echo a & echo b` 先执行 `a`（后台），再执行 `b`；
- `|&` 里的 `&` 不算分隔符。

### 1.1 重定向

```text
重定向   := 输出重定向 | 错误重定向 | 输入重定向 | 全量重定向 | 合并错误
输出重定向 := (">" | ">>") 目标               // `>` 后面紧跟 `>` 才算追加
错误重定向 := "2>" 目标 | "2>>" 目标          // `2` 必须位于词首且后面紧跟 `>`
输入重定向 := "<" 目标
全量重定向 := ("&>" | "&>>") 目标             // 标准输出与标准错误一起
合并错误   := "2>&1"
```

`2>` 的 `2` 只在「一个新词的开头」且紧跟 `>` 时才算描述符前缀，所以 `echo 2-3`、`echo a1>o.txt`（输出到 `o.txt`，参数是 `a1`）都按普通词/普通重定向处理。

连续写两个重定向目标（`<> b`）会报「重定向缺少目标文件」。

同一位置重复出现时**以后写的为准**：

```text
echo a >甲 2>乙        # 标准输出到甲，标准错误到乙
echo a 2>&1 >甲        # 标准错误跟随标准输出，标准输出到甲
echo a &>甲 2>乙       # &> 同时设置两者，随后的 2>乙 覆盖标准错误
```

## 2. 词法

### 2.1 空白与分隔符

- `空格`、`Tab`、`\r` 分隔词；
- 以下字符在**未加引号**时是操作符：`|` `&` `;` `<` `>` `(` `)`——出现在词中间也会断开词。

### 2.2 词

```text
词        := 词片段+
词片段    := 裸片段 | 双引号串 | 单引号串 | 反斜杠转义
裸片段    := 除 空白、操作符、引号、反斜杠、`$` 之外的任意字符
反斜杠转义 := "\\" 任意字符          // 保留该字符的字面值
双引号串  := '"' 双引号字符* '"'
单引号串  := '\'' 单引号字符* '\''
```

引号**只决定怎么展开**，引号本身不会成为参数的一部分：

| 片段 | 规则 |
| --- | --- |
| 裸片段 | `$` 展开、`~` 展开、`*` `?` `[` 通配 |
| 双引号串 | 只展开 `$`；不做通配、不做 `~`；空白不切分 |
| 单引号串 | 完全字面量（`$`、通配、`~` 都不认） |
| `\字符` | 字面量，且不切分 |

引号保护**按字符生效**，所以相邻片段可以混写：

```text
echo 'A'"$HOME"      # A/home   —— 只有单引号内那段是字面量
echo "a b"c          # 一个参数：a bc
echo ''#             # 一个参数：#
```

### 2.3 各引号内允许的转义

| 位置 | 可转义 | 说明 |
| --- | --- | --- |
| 词内（引号外） | 任意字符 | `\ ` `\*` `\<` `\$` 都按字面处理，`\`+换行 = 续行 |
| 单引号内 | 只有 `\'` | 其它 `\` 按普通字符保留；例如 `'a\b'` 得到 `a\b` |
| 双引号内 | `\"` `\\` `\$` `` \` `` | 其它 `\ x` 保留反斜杠（例如 `"a\tb"` 得到 `a\tb` 字面）；`\`+换行 = 续行 |

> 注意：双引号里的 `\n`、`\t` **不会**变成换行/制表符，请用 `echo -e` 或 `$'\n'`（不支持）。

### 2.4 上例的实际结果

```text
echo '$HOME'        →  $HOME
echo \$HOME         →  $HOME
echo "a\tb"         →  a\tb     （反斜杠保留）
echo "a\\b"         →  a\b
echo 'a\'b'         →  a'b
echo 'a\b'          →  a\b      （单引号里 `\b` 不转义）
```

### 2.5 `#` 注释

- `#` 出现在**一个词的开头位置**时，其后到行尾全部是注释；
- 出现在词中间时是普通字符：`a#b` 就是一个参数 `a#b`；
- 在引号内也是普通字符：`echo "#"` 输出 `#`。

```text
echo a # 注释        →  a
echo a#b             →  a#b
```

## 3. 赋值

```text
赋值 := 名称 "=" 值词
值词 := 与普通词相同（同样受引号影响）
```

- `名称=值` 单独出现（没有命令词）时，修改 **shell 自身**的变量，同时写进进程环境；
- `名称=值 命令` 时，只作为该命令（子进程）的环境覆盖，shell 自身的变量不变；
- `=` 必须**没有**出现在引号里：`"a=b"` 是普通词；
- 名称取「第一个未加引号的 `=`」之前的字符，必须是合法的变量名，否则整个词作普通词。

```text
X=外层
X=内层 env | grep ^X=      →  X=内层
echo $X                    →  外层
```

## 4. 展开

展开在解析完成、真正执行前进行，按下面的顺序：

```text
词 ──(1) 变量/波浪号展开──► 一个字符串 ──(2) 通配展开──► 零个或多个参数
```

### 4.1 变量展开

| 写法 | 含义 |
| --- | --- |
| `$名称` | 变量值；`名称` = 连续的字母、数字、`_` |
| `${名称}` | 同上，用大括号明确边界，可处理 `$名称后缀` 这种连写 |
| `$?` | 上一条命令的退出状态 |
| `$$` | 当前 shell 进程号 |
| `$!` | 最近一次后台作业的进程号（没有则 0） |
| `$#` | 位置参数个数 |
| `$@` / `$*` | 全部位置参数（空格连接） |
| `$0` | 脚本名 |
| `$1`、`$2`…… | 位置参数 |
| `$参数` | 第一个位置参数（没有则为空串，写法同 `$1`） |
| `$参数列表` | 全部位置参数，空格连接（同 `$@`） |
| `$参数个数` | 位置参数个数（同 `$#`） |
| `$参数对象` | 标准参数解析结果，JSON 文本，见 4.2 |
| `$当前目录` | 进程当前工作目录，取值时实时获取（`进入` 之后立即变化） |
| `$脚本路径` | 当前正在执行的脚本：命令行参数原样（`壳 子/外.壳` 得 `子/外.壳`）；顶层脚本执行完、非脚本场景为空串 |
| `$脚本目录` | 当前执行脚本所在的绝对目录（`导入` 嵌套时逐层切换，返回后恢复） |

- 未定义的变量展开为**空串**；
- `$` 后面是 `?` `$` `!` `#` `@` `*` 时按特殊变量展开；其它既非名称字符也非 `{` 的字符，`$` 当普通字符（如 `echo $` 输出 `$`）；
- `$` 若位于单引号内，不展开；位于双引号内，展开；
- 变量名里允许中文，但中文标点（`。`、`，`、`：`、全角括号等）视为名字结束；
- 不支持的写法（会按字面处理或报错）：`$((...))`（报「意外的符号 `(`」）、`$'...'`、`` `...` ``、`${名称:-默认值}`。

### 4.2 其它默认变量

| 变量 | 含义 |
| --- | --- |
| `$当前目录` | 进程当前工作目录，取值时实时获取 |
| `$脚本路径` | 当前执行的脚本，命令行原样；不在脚本里或顶层脚本执行完为空串 |
| `$脚本目录` | 当前执行脚本所在的绝对目录 |
| `$返回值对象` | 最近一次 `读取文本` 的结果，表达式形式（如 `{键=值 列表=(a b)}`） |
| `$返回值JSON` | 同一结果的 JSON 文本 |

### 4.3 `$参数对象`

位置参数经标准参数解析后写成 JSON 的**有序对象**，固定四个键：

```text
{"命令行":[...],"选项":{...},"分隔符":"--","剩余":[...]}
```

| 键 | 含义 |
| --- | --- |
| `命令行` | 既不是选项、也不在 `--` 之后的参数，按原顺序 |
| `选项` | 选项表：`--名=数据` 取 `数据`；`--名`（或 `--开关`）取 `"true"`；单独的 `-` 记为 `选项.- = "true"`；单个横线的 `-名` 后面紧跟一个不以 `-` 开头的词时，把该词当它的数据 |
| `分隔符` | 第一个 `--` 本身（没有则为空串）；它之后的参数全部进 `剩余` |
| `剩余` | `--` 之后的参数，原样 |

```text
壳 脚本 --parse 构建 --release --输出 json --file=数据.txt -- 剩余一 剩余二
$参数对象 → {"命令行":["构建","json"],"选项":{"release":"true","输出":"true","file":"数据.txt"},"分隔符":"--","剩余":["剩余一","剩余二"]}
```

`$参数对象` 是文本形式，`$参数列表`/`$参数个数` 里的 `--` 及之后的内容仍算在位置参数内（即与 `$1…$n` 一致）。

### 4.4 波浪号展开

只在**词首**、**不在引号内**、且整个词里没有双引号时生效：

| 写法 | 结果 |
| --- | --- |
| `~` | `$HOME` |
| `~/路径` | `$HOME/路径` |
| `~x`、`a~` | 原样（不支持 `~用户名`） |
| `'~'`、`"~"` | 原样 |

### 4.5 通配展开

| 模式 | 匹配 |
| --- | --- |
| `*` | 任意长度的字符序列（允许为空） |
| `?` | 恰好一个字符 |
| `[abc]` | 集合中的任意一个字符 |
| `[a-z]` | 字符范围（按 Unicode 码位比较） |
| `[!abc]` / `[^abc]` | 不在集合中 |
| `[` 没有配对的 `]` | 当作普通字符 `[` |

规则：

- 只对**含路径的最后一段**做文件名匹配：`日志/*.txt` 先匹配 `日志/` 下的文件名，再拼回前缀；中间段不支持通配；
- 以 `.` 开头的隐藏文件，只有模式本身也以 `.` 开头时才会被匹配；
- 结果按字符串排序；
- **没有匹配项时保留原样**（不报错，与 bash 默认行为一致）；
- 只有词里**原样写出**的通配符才生效：单引号内的、双引号内的、以及变量展开出来的 `*` 都不会被通配。

```text
touch 甲.rs 乙.rs
echo *.rs          →  乙.rs 甲.rs
echo '*.rs'        →  *.rs
x='*.rs'; echo $x  →  *.rs
echo *.none        →  *.none
```

### 4.4 切分规则

- 不加引号的词：展开后若整体为空串，**该词消失**（不产生参数）；
- 加引号的词（`''` 或 `""`）：即使为空也**保留一个空参数**；
- 本 shell **不做**按空格二次切分：`x='a b'; echo $x` 得到 `a b` 一个参数（bash 会切成两个）。

## 5. 内置命令与保留词

```text
进入  压栈  弹栈  导出  导入  退出
删除  输出  回显  运行  帮助  正常  错误  读取文本

控制流保留词：如果  或者  否则  对于  每当  跳出  继续
函数保留词：函数  返回
（加引号时仍是普通命令名，例如 `"如果" arg` 会查找名为「如果」的程序）
```

`读取文本` 的语法：

```text
读取文本 文件                    // 按扩展名推断类型：.ini/.conf → INI，其余（含 .json）→ JSON
读取文本 文件 --类型 类型
读取文本 文件 --类型=类型
读取文本 文件 --类型名            // 如 --JSON、--ini
                                 // 类型不区分大小写：JSON、INI、文本
结果放在 $返回值对象（表达式文本）与 $返回值JSON（JSON 文本）；
文件读不到、类型不认识、解析失败时返回 1，$返回值对象 清空。
```

`导出` 的语法：

```text
导出                     // 列出全部：每行 `名称=数据`，按名称排序
导出 名称=数据 ...       // 设置并导出；数据是一个词，引号规则同普通词：
                         //   不带引号 —— 到空白或操作符为止
                         //   双引号   —— 可含空格，$ 照常展开
                         //   单引号   —— 纯文本，$ 与通配都不展开
导出 名称=              // 数据留空 —— 删除该变量
```

名称必须合法（`字母|_` 开头，后接 `字母|数字|_`），否则该条报错、状态码 1；缺少 `=` 同样报错。

- 内置命令出现时**优先于同名的外部程序**；
- 单独出现（不在管道、不在后台）时在 shell 自身进程里执行，因此 `进入`、`导出`、`删除`、`压栈`、`弹栈`、`导入` 会改变 shell；
- 在管道或后台里时，由子进程执行，不会改变 shell；
- `正常`/`错误`/`退出` 等没有外部依赖，可放心用于脚本。
- `导入 文件...` 是内置命令，脚本内容在当前 shell 里逐行解析，语法同交互输入（空行与 `#` 注释照常忽略）。

`输出` 直接写出、不追加回车；`回显` 默认追加回车，选项：`-n`（不回车）、`-e`（解释 `\n` `\t` `\r` `\\` `\e`）以及 `-ne`/`-en`。

## 6. 退出状态

| 情形 | 状态码 |
| --- | --- |
| 外部命令正常退出 | 程序的退出码 0–255 |
| 外部命令被信号 N 终止 | `128 + N` |
| 命令不存在 | 127 |
| 命令存在但无执行权限 | 126 |
| 内置命令执行失败 | 1 |
| 语法错误 | 2 |
| 重定向目标打不开 | 1 |
| 纯赋值 / 空行 / 注释行 | 0 |

- 一条管道（含多条命令）的最终状态取**最后一段**（与 bash 默认一致）；
- `壳 -c '...'` 的进程退出码 = 最后一条作业的状态；`退出 N`则直接返回 N；
- 启动文件 `~/.壳语言rc` 执行完后状态码归零。

## 7. 语法错误清单

| 错误 | 触发例 |
| --- | --- |
| `引号 ' 未闭合` / `引号 " 未闭合` | `echo 'abc` |
| `行尾反斜杠没有可转义的字符` | `echo abc\` |
| `缺少命令` | `\| echo`、`echo a \|`、`& echo`、`echo a && echo b` |
| `重定向缺少目标文件` | `echo a >`、`cat <` |
| `意外的符号 `(`` / `)` | `(echo a)`、`echo $((1+2))` |
| `展开后没有可执行的命令` | `echo a \|\| b` 在展开后某一段为空 |

每条错误只影响**当前一行**：该行剩下的命令不执行，shell 继续处理下一行；`-c` 模式下进程以 2 退出。

## 8. 完整示例

```sh
# 变量与引号
名字=壳语言
echo 你好${名字}人                # 你好壳语言人
echo '$名字'                      # $名字
导出 名字=$名字; sh -c "echo $名字"  # 壳语言

# 管道与重定向
printf '甲\n乙\n甲\n' | sort | uniq -c
ls /不存在的路径 2>&1 | wc -l      # 1
echo 第一版 > 笔记.txt; echo 补充 >> 笔记.txt
```

## 9. 未实现的语法（写了会得到什么）

| 想写 | 实际结果 |
| --- | --- |
| `a && b` / `a \|\| b` | 语法错误：缺少命令 / 报「展开后没有可执行的命令」 |
| 反引号 `` `命令` `` | 按普通字符处理（请用 `$(命令)`） |
| `(命令)` 子 shell | 语法错误：意外的符号 |
| `{ 命令; }` | `{`、`}` 按普通词处理（多数情况会「未找到命令」） |
| `case` | 按普通命令去查找同名程序，通常「未找到命令」 |
| `\|\|`、`&!`、`>|` | 分别按 `\|` + `&`… 的组合解析，结果见上 |
| `~用户`、`$'...'`、`${名:-默认}` | 按字面量原样传给程序 |
| 行内 `VAR=值` 后再引用（`x=1 echo $x`） | `$x` 取的是赋值前的值（前置赋值只影响子进程环境） |
| 反引号 `` `命令` `` | 按普通字符传给程序，不执行 |
