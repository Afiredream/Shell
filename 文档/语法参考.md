# 壳语言 语法参考

> 本文是**形式化的语法**：词法、文法、展开规则、退出状态。
> 只想知道怎么写命令请看 [使用手册](使用手册.md)；想改解析器请看 [实现说明](实现说明.md)。

## 0. 记号

| 记号 | 含义 |
| --- | --- |
| `甲 乙` | 甲后面跟乙（顺序连接） |
| `甲*` | 甲出现零次或多次（后缀 `*`，与正则无关） |
| `甲?` | 甲出现零次或一次 |
| `[甲]` | 甲可省略 |
| `"..."` | 源文本里的字面字符 |
| `甲 \| 乙` | 二选一 |

本 shell 支持多行控制流块，也支持在一行内写管道、重定向等。控制流用中文关键字与 `结束` 配对，
缩进只是排版；块可嵌套，块体在**当前 shell** 执行（变量、`cd`、目录栈的改动会保留）：

```text
如果 <条件命令>           // 退出码 0 为真
    <语句...>
或者 <条件命令>           // 可多次，可省略
    <语句...>
否则                      // 可省略
    <语句...>
结束

对于 <变量> 在 <词1> <词2> ...
    <语句...>
结束

每当 <条件命令>
    <语句...>
结束

跳出 / 继续               // 退出循环 / 进入下一轮

函数 <名称> <参数名...>    // 定义时不执行，调用时才执行函数体
    <语句...>
结束

返回 [码]                 // 从函数返回；码省略时取上一条命令的状态
```

条件是一条命令/管道，可用 `真`/`假`、`true`/`false` 或外部 `test`。
块头必须独占一行，条件不能使用后台（`异步运行` / `&`），否则取不到退出码。

## 1. 一行输入的文法

```text
行        := 空白* [作业项 ( 分隔符 作业项 )* ] 注释? 空白*
分隔符    := ";" | "&" | "\n"                     // 旧写法 `&` 同时把前一项放进后台
作业项    := ["异步运行"] 管道 重定向*              // 「异步运行」把整条作业放进后台
管道      := 简单命令 ( 管道符 简单命令 )*
管道符    := "|" | "|&"
简单命令  := 赋值* ( 词+ 重定向* )?                  // 只有赋值时是「纯赋值命令」
赋值      := 名称 "=" 值词
名称      := (字母 | "_") (字母 | 数字 | "_")*
```

补充规则：

- 重定向可以写在管道任意段的前后，但**归属整条作业**：
  - `>` / `>>`：整条作业（即最后一段）的标准输出，`echo b | cat > 文件` 与 `echo b > 文件 | cat` 都把 `b` 写进文件；
  - `<`：整条作业（即第一段）的标准输入，**并且优先于管道**。`echo b | cat < 有内容.txt` 输出文件里的内容、`b` 被丢弃；
  - `2>` / `2>&1`：作用于按顺序等待时第一个还没结束的段——对单段命令就是它自己；
- `;` 与换行等价；连续写 `;;` 不会报错（空语句被忽略）；
- `异步运行` 是后台关键字，写在作业开头：`异步运行 echo a` 把**整条作业**放进后台；
  它只在命令名位置、未被引号包住时生效，单独写（后面没有命令）报「缺少命令」；
- 旧写法 `&` 是分隔符 + 后台标记：`echo a & echo b` 先执行 `a`（后台），再执行 `b`；
- `|&` 里的 `&` 不算分隔符。

### 1.1 重定向

```text
重定向   := 输出重定向 | 错误重定向 | 输入重定向 | 全量重定向 | 合并错误
输出重定向 := (">" | ">>") 目标               // `>` 后面紧跟 `>` 才算追加
错误重定向 := "2>" 目标 | "2>>" 目标          // `2` 必须位于词首且后面紧跟 `>`
输入重定向 := "<" 目标
全量重定向 := ("&>" | "&>>") 目标             // 标准输出与标准错误一起
合并错误   := "2>&1"
```

`2>` 的 `2` 只在「一个新词的开头」且紧跟 `>` 时才算描述符前缀，所以 `echo 2-3`、`echo a1>o.txt`（输出到 `o.txt`，参数是 `a1`）都按普通词/普通重定向处理。

连续写两个重定向目标（`<> b`）会报「重定向缺少目标文件」。

同一位置重复出现时**以后写的为准**：

```text
echo a >甲 2>乙        # 标准输出到甲，标准错误到乙
echo a 2>&1 >甲        # 标准错误跟随标准输出，标准输出到甲
echo a &>甲 2>乙       # &> 同时设置两者，随后的 2>乙 覆盖标准错误
```

## 2. 词法

### 2.1 空白与分隔符

- `空格`、`Tab`、`\r` 分隔词；
- 以下字符在**未加引号**时是操作符：`|` `&` `;` `<` `>` `(` `)`——出现在词中间也会断开词。

### 2.2 词

```text
词        := 词片段+
词片段    := 裸片段 | 双引号串 | 单引号串 | 反斜杠转义
裸片段    := 除 空白、操作符、引号、反斜杠、`$` 之外的任意字符
反斜杠转义 := "\\" 任意字符          // 保留该字符的字面值
双引号串  := '"' 双引号字符* '"'
单引号串  := '\'' 单引号字符* '\''
```

引号**只决定怎么展开**，引号本身不会成为参数的一部分：

| 片段 | 规则 |
| --- | --- |
| 裸片段 | `$` 展开、`~` 展开、`*` `?` `[` 通配 |
| 双引号串 | 只展开 `$`；不做通配、不做 `~`；空白不切分 |
| 单引号串 | 完全字面量（`$`、通配、`~` 都不认） |
| `\字符` | 字面量，且不切分 |

引号保护**按字符生效**，所以相邻片段可以混写：

```text
echo 'A'"$HOME"      # A/home   —— 只有单引号内那段是字面量
echo "a b"c          # 一个参数：a bc
echo ''#             # 一个参数：#
```

### 2.3 各引号内允许的转义

| 位置 | 可转义 | 说明 |
| --- | --- | --- |
| 词内（引号外） | 任意字符 | `\ ` `\*` `\<` `\$` 都按字面处理，`\`+换行 = 续行 |
| 单引号内 | 只有 `\'` | 其它 `\` 按普通字符保留；例如 `'a\b'` 得到 `a\b` |
| 双引号内 | `\"` `\\` `\$` `` \` `` | 其它 `\ x` 保留反斜杠（例如 `"a\tb"` 得到 `a\tb` 字面）；`\`+换行 = 续行 |

> 注意：双引号里的 `\n`、`\t` **不会**变成换行/制表符，请用 `echo -e` 或 `$'\n'`（不支持）。

### 2.4 上例的实际结果

```text
echo '$HOME'        →  $HOME
echo \$HOME         →  $HOME
echo "a\tb"         →  a\tb     （反斜杠保留）
echo "a\\b"         →  a\b
echo 'a\'b'         →  a'b
echo 'a\b'          →  a\b      （单引号里 `\b` 不转义）
```

### 2.5 `#` 注释

- `#` 出现在**一个词的开头位置**时，其后到行尾全部是注释；
- 出现在词中间时是普通字符：`a#b` 就是一个参数 `a#b`；
- 在引号内也是普通字符：`echo "#"` 输出 `#`。

```text
echo a # 注释        →  a
echo a#b             →  a#b
```

## 3. 赋值

```text
赋值 := 名称 "=" 值词
值词 := 与普通词相同（同样受引号影响）
```

- `名称=值` 单独出现（没有命令词）时，修改 **shell 自身**的变量，同时写进进程环境；
- `名称=值 命令` 时，只作为该命令（子进程）的环境覆盖，shell 自身的变量不变；
- `=` 必须**没有**出现在引号里：`"a=b"` 是普通词；
- 名称取「第一个未加引号的 `=`」之前的字符，必须是合法的变量名，否则整个词作普通词。

```text
X=外层
X=内层 env | grep ^X=      →  X=内层
echo $X                    →  外层
```

## 4. 展开

展开在解析完成、真正执行前进行，按下面的顺序：

```text
词 ──(1) 变量/波浪号展开──► 一个字符串 ──(2) 通配展开──► 零个或多个参数
```

### 4.1 变量展开

| 写法 | 含义 |
| --- | --- |
| `$名称` | 变量值；`名称` = 连续的字母、数字、`_` |
| `${名称}` | 同上，用大括号明确边界，可处理 `$名称后缀` 这种连写 |
| `$?` | 上一条命令的退出状态 |

- 未定义的变量展开为**空串**；
- `$` 后面不是字母/数字/`{`/`_` 时，`$` 当普通字符：`echo $` 输出 `$`；
- `$` 若位于单引号内，不展开；位于双引号内，展开；
- 变量名里允许中文，但中文标点（`。`、`，`、`：`、全角括号等）视为名字结束；
- 不支持的写法（会按字面处理或报错）：`$((...))`（报「意外的符号 `(`」）、`$'...'`、`` `...` ``、`${名称:-默认值}`。

### 4.2 波浪号展开

只在**词首**、**不在引号内**、且整个词里没有双引号时生效：

| 写法 | 结果 |
| --- | --- |
| `~` | `$HOME` |
| `~/路径` | `$HOME/路径` |
| `~x`、`a~` | 原样（不支持 `~用户名`） |
| `'~'`、`"~"` | 原样 |

### 4.3 通配展开

| 模式 | 匹配 |
| --- | --- |
| `*` | 任意长度的字符序列（允许为空） |
| `?` | 恰好一个字符 |
| `[abc]` | 集合中的任意一个字符 |
| `[a-z]` | 字符范围（按 Unicode 码位比较） |
| `[!abc]` / `[^abc]` | 不在集合中 |
| `[` 没有配对的 `]` | 当作普通字符 `[` |

规则：

- 只对**含路径的最后一段**做文件名匹配：`日志/*.txt` 先匹配 `日志/` 下的文件名，再拼回前缀；中间段不支持通配；
- 以 `.` 开头的隐藏文件，只有模式本身也以 `.` 开头时才会被匹配；
- 结果按字符串排序；
- **没有匹配项时保留原样**（不报错，与 bash 默认行为一致）；
- 只有词里**原样写出**的通配符才生效：单引号内的、双引号内的、以及变量展开出来的 `*` 都不会被通配。

```text
touch 甲.rs 乙.rs
echo *.rs          →  乙.rs 甲.rs
echo '*.rs'        →  *.rs
x='*.rs'; echo $x  →  *.rs
echo *.none        →  *.none
```

### 4.4 切分规则

- 不加引号的词：展开后若整体为空串，**该词消失**（不产生参数）；
- 加引号的词（`''` 或 `""`）：即使为空也**保留一个空参数**；
- 本 shell **不做**按空格二次切分：`x='a b'; echo $x` 得到 `a b` 一个参数（bash 会切成两个）。

## 5. 内置命令与保留词

```text
进入目录  压栈目录  弹栈目录  打印目录  环境变量  加载脚本  退出进程
unset   输出文本  替换运行  help    true    false
旧名：cd  pushd  popd  pwd  export  env  source  exit  echo  exec

控制流保留词：如果  或者  否则  对于  在  每当  结束  跳出  继续
函数保留词：函数  返回
（加引号时仍是普通命令名，例如 `"如果" arg` 会查找名为「如果」的程序）
```

`环境变量` 的语法：

```text
环境变量                 // 列出全部：每行 `名称=数据`，按名称排序
环境变量 名称=数据 ...   // 设置并导出；数据是一个词，引号规则同普通词：
                         //   不带引号 —— 到空白或操作符为止
                         //   双引号   —— 可含空格，$ 照常展开
                         //   单引号   —— 纯文本，$ 与通配都不展开
```

名称必须合法（`字母|_` 开头，后接 `字母|数字|_`），否则该条报错、状态码 1；缺少 `=` 同样报错。
`export` 是 `环境变量` 的旧名，`env` 等价于不带参数的 `环境变量`。

- 内置命令出现时**优先于同名的外部程序**；
- 单独出现（不在管道、不在后台）时在 shell 自身进程里执行，因此 `进入目录`、`环境变量`、`unset`、`压栈目录`、`弹栈目录`、`加载脚本` 会改变 shell；
- 在管道或后台里时，由子进程执行，不会改变 shell；
- `true`/`false`/`退出进程` 等没有外部依赖，可放心用于脚本。
- `加载脚本 文件...` 是内置命令，脚本内容在当前 shell 里逐行解析，语法同交互输入（空行与 `#` 注释照常忽略）。

`echo` 的选项：`-n`（结尾不换行）、`-e`（解释 `\n` `\t` `\r` `\\` `\e`）以及它们的组合 `-ne`/`-en`。

## 6. 退出状态

| 情形 | 状态码 |
| --- | --- |
| 外部命令正常退出 | 程序的退出码 0–255 |
| 外部命令被信号 N 终止 | `128 + N` |
| 命令不存在 | 127 |
| 命令存在但无执行权限 | 126 |
| 内置命令执行失败 | 1 |
| 语法错误 | 2 |
| 重定向目标打不开 | 1 |
| 纯赋值 / 空行 / 注释行 | 0 |

- 一条管道（含多条命令）的最终状态取**最后一段**（与 bash 默认一致）；
- `壳 -c '...'` 的进程退出码 = 最后一条作业的状态；`退出进程 N`（旧名 `exit N`）则直接返回 N；
- 启动文件 `~/.壳语言rc` 执行完后状态码归零。

## 7. 语法错误清单

| 错误 | 触发例 |
| --- | --- |
| `引号 ' 未闭合` / `引号 " 未闭合` | `echo 'abc` |
| `行尾反斜杠没有可转义的字符` | `echo abc\` |
| `缺少命令` | `\| echo`、`echo a \|`、`& echo`、`echo a && echo b` |
| `重定向缺少目标文件` | `echo a >`、`cat <` |
| `意外的符号 `(`` / `)` | `(echo a)`、`echo $((1+2))` |
| `展开后没有可执行的命令` | `echo a \|\| b` 在展开后某一段为空 |

每条错误只影响**当前一行**：该行剩下的命令不执行，shell 继续处理下一行；`-c` 模式下进程以 2 退出。

## 8. 完整示例

```sh
# 变量与引号
名字=壳语言
echo 你好${名字}人                # 你好壳语言人
echo '$名字'                      # $名字
环境变量 名字=$名字; sh -c "echo $名字"  # 壳语言

# 管道与重定向
printf '甲\n乙\n甲\n' | sort | uniq -c
ls /不存在的路径 2>&1 | wc -l      # 1
echo 第一版 > 笔记.txt; echo 补充 >> 笔记.txt

# 通配与波浪号
echo ~/文档/*.txt
echo [甲乙].rs

# 后台（旧写法 sleep 3 & 仍可用）
异步运行 sleep 3
```

## 9. 未实现的语法（写了会得到什么）

| 想写 | 实际结果 |
| --- | --- |
| `a && b` / `a \|\| b` | 语法错误：缺少命令 / 报「展开后没有可执行的命令」 |
| `$(命令)` / `` `命令` `` | `(` 报「意外的符号」；反引号按普通字符处理 |
| `(命令)` 子 shell | 语法错误：意外的符号 |
| `{ 命令; }` | `{`、`}` 按普通词处理（多数情况会「未找到命令」） |
| `case` | 按普通命令去查找同名程序，通常「未找到命令」 |
| `\|\|`、`&!`、`>|` | 分别按 `\|` + `&`… 的组合解析，结果见上 |
| `~用户`、`$'...'`、`${名:-默认}` | 按字面量原样传给程序 |
| 行内 `VAR=值` 后再引用（`x=1 echo $x`） | `$x` 取的是赋值前的值（前置赋值只影响子进程环境） |
| 反引号 `` `命令` `` | 按普通字符传给程序，不执行 |
