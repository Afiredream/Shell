## 一分钟上手

```sh
cargo build --release
./构建/release/壳                    # 交互模式
./构建/release/壳 -c 'ls | wc -l'    # 执行一条命令
```

## 项目速览

- 语言：Rust（edition 2021），依赖见 README「依赖与许可证」
- 体积：8 个源文件，约 2100 行（含注释与测试）
- 命名：目录、文件、类型、函数、变量一律中文（详见实现说明第 8 节）
- 平台：Linux（Arch / glibc 下验证）

```text
源码/
├── 主体.rs            # 入口
└── 模块/
    ├── 模块.rs        # 模块索引
    ├── 词法.rs        # 分词、语法、引号、展开、通配匹配
    ├── 释义.rs        # 作业 → 管道片段
    ├── 执行.rs        # 分叉、管道、重定向、等待
    ├── 内置.rs        # 内置命令
    ├── 壳.rs          # 调度器
    └── 系统.rs        # C 库绑定
```
