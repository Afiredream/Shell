## 2. 开发中踩过的坑（排错时先看这里）

### 2.1 管道读端永远等不到 EOF

**现象**：`seq 1 100 | wc -l` 卡住。
**原因**：父进程分叉完没有关闭管道写端——即使所有子进程都退出了，写端还开着，读端就等不到 EOF。
**做法**：子进程里 `重定向描述符` 接好之后立刻关闭两端；父进程在分叉循环结束后关闭全部管道端。

### 2.2 `dup2: Bad file descriptor`

**现象**：`cat < 文件`、`printf ... | cat | wc -l` 报 `重定向描述符` 失败。
**原因**：在完成 dup 之前就把「本进程要用」的管道端关掉了。
**做法**：先只关闭本进程**用不到**的端，要用的端记在变量里，dup 完再关。

### 2.3 `yes | head -1` 卡住

**现象**：`head` 已经打印完毕并退出，shell 还在等 `yes`。
**原因**：shell 自己继承了「忽略 SIGPIPE」，`yes` 写管道时收不到 SIGPIPE，一直写。
**做法**：子进程 `恢复信号默认()`；并且任意一段被信号终止时走 `收尾`，不再等上游。

### 2.4 后台作业在 `-c` 模式结束后被挂起

**现象**：`壳 -c 'sleep 1 &'` 之后，那个 `sleep` 进程停住（`ps` 里状态为 `T`）—— 未启用作业控制时的典型表现。
**原因**：子进程的标准输入仍连着终端但不在前台进程组，读终端会收到 SIGTTIN。
**做法**：后台作业 `设置进程组(0, 0)` 自成一组。

### 2.5 退出 shell 时命令被 Ctrl-C 打断

**现象**：`Command` 建立的子进程偶尔直接退出。
**原因**：Rust 的 `Command` 会在分叉到换程序之间短暂屏蔽信号，若 shell 此时把 SIGINT 恢复成默认，就会命中。
**做法**：shell 先 `设置信号处理(SIGINT, 忽略信号)` 再分叉，子进程换程序前再恢复默认。

### 2.6 中文变量名导致崩溃

**现象**：`名字=值` 引发 `not a char boundary` panic。
**原因**：赋值识别时用「字符数」当「字节偏移」去切字符串，中文占多字节会切在字符中间。
**做法**：统一按 `chars()` 切分（`收集词` 里的「去掉名称与等号」那一段）；已补测试 `中文变量赋值`。

### 2.7 单引号里面写单引号

**现象**：`回显 'a\'b'` 报「引号 ' 未闭合」。
**原因**：实现早期单引号内不认任何转义。
**修复**：单引号内按 bash 的规则只认 `\'`；引号保护改为**按字符记录**（`词` 里的字面量区），所以 `'a'$HOME` 能正确展开 `$HOME`。

### 2.8 重定向把换行吞进文件名

**现象**：从标准输入逐行执行时，`回显 hi > 输出.txt` 生成了一个名字末尾带换行的文件，后面几行也被当成同一个目标。
**原因**：重定向目标的读法在判断「词是否结束」时只看空白字符集，而行尾换行不在其中，于是换行被当成文件名的一部分。
**修复**：空白集合加入换行；重定向目标读取改为「逐个字符推进游标」的单一循环（[`源码/主体.rs`](../源码/主体.rs) 的 `read_redirect_target`），并补测试 `重定向目标不吃换行`。

### 2.9 引号语义混淆

**现象**：`sh -c 'echo $名字'` 输出 `$名字`；`'A'$HOME` 不展开。
**原因**：不是 bug，是规则——单引号内的 `$` 不展开（按字符保护，单引号外面的部分照常展开）。
**用法**：需要子 shell 看到变量时写 `sh -c "echo $名字"`（双引号，且先 `导出 名字`）。

## 3. 报错对照

| 输出 | 含义 | 排查方向 |
| --- | --- | --- |
| `语法错误：引号 X 未闭合` | 引号没配对 | 检查引号 |
| `语法错误：缺少命令` | `\|`/`&`/`;` 后为空，或用了 `&&`/`\|\|` | 补齐命令或换写法 |
| `语法错误：重定向缺少目标文件` | 重定向符号后没有文件名 | 补文件名 |
| `语法错误：意外的符号 `(`` | 不支持子 shell | 改 `sh -c '...'` |
| `语法错误：行尾反斜杠没有可转义的字符` | 行末孤立 `\` | 删除或补字符 |
| `壳: 程序: 未找到命令` | execvp 返回 ENOENT | 检查 `PATH`、拼写 |
| `壳: 程序: 权限不足` | EACCES | `chmod +x` |
| `壳: 路径: No such file or directory` | 重定向目标打不开 | 检查目录 |
| `创建子进程失败 / 创建管道失败` | 系统资源不足 | 检查进程数上限 |

## 4. 已知限制（不是 bug）

- 只面向 Linux（`O_*` 常量按 Linux 取值，glibc 下验证）；
- 没有 `&&`/`||`/子 shell，也没有 `jobs`/`fg`/`bg`；
  控制流用中文的 `如果`/`或者`/`否则`、`对于`、`每当` 实现（块用缩进，不用 `结束`）；
  函数用 `函数`/`返回` 实现；
- 后台作业结束不打印通知（没有 SIGCHLD 处理），由系统回收；
- 没有交互模式：不带参数运行会打印帮助并返回 2，不提供提示符、行编辑或历史；脚本里的前台命令仍可被 `Ctrl-C` 终止（子进程恢复默认处理）；
- `$变量` 展开出来的内容不再参与通配；
- 反斜杠可以转义任意字符（包括 `<`、`|`），与 bash 只在少数语境允许转义不同；
- 启动文件只读 `~/.壳语言rc`，没有系统级配置。
